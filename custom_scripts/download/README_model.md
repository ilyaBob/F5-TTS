## download_model.py — Загрузка весов модели и словаря с Hugging Face
Скрипт предназначен для автоматического скачивания предобученных чекпоинтов (весов модели) и словаря vocab.txt из репозиториев на Hugging Face и их сохранении в целевую директорию проекта F5-TTS.

Что делает скрипт:
Авторизация на Hugging Face: Загружает учетные данные из переменных окружения или файла .env для работы с приватными или ограниченными репозиториями.

Загрузка весов модели: Скачивает указанный файл чекпоинта (.pt) в целевую директорию чекпоинтов F5-TTS.

Гарантированная загрузка словаря: Проверяет наличие vocab.txt. Если файл отсутствует в основном репозитории, автоматический fallback-механизм скачивает его из запасного репозитория.

Обработка ошибок и откат: В случае проблем со связью или отсутствия доступа проверяет локальное наличие файлов и предотвращает сбой при имеющейся рабочей копии.

Что создаётся в результате работы:
В директории /content/F5-TTS/ckpts/{MODEL_DIR_NAME} создаются или обновляются файлы:

<FILE_NAME> — файл с весами модели (например, model_800.pt).

vocab.txt — словарь символов/токенов для текстового инференса.

Источники данных:
Переменные окружения или конфигурационный файл .env с ключами доступа и параметрами репозитория.

Удаленные репозитории модели на платформе Hugging Face Hub.

Требования для запуска:
Установленные библиотеки Python: huggingface_hub, python-dotenv (опционально, для работы с .env).

Созданный и заполненный файл .env в корне проекта.

Переменные, которые должны быть заданы в .env:

### Заполнить в .env

- HF_TOKEN=hf_xxx
- HF_REPO_MODEL=user/repo-name
- FILE_NAME=model_800.pt
- MODEL_DIR_NAME=my_voice
- FALLBACK_VOCAB_REPO=user/fallback-repo-name

Запуск:
Bash
```python download_model.py```
