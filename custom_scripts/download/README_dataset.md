## download_dataset.py — Загрузка эталонного аудиофайла датасета с Hugging Face
Скрипт предназначен для скачивания конкретного референсного аудиофайла из приватного или публичного репозитория датасетов на Hugging Face для последующего использования при инференсе и генерации речи в F5-TTS.

Что делает скрипт:
Чтение конфигурации: Читает токены доступа, названия репозиториев и пути к файлам из файла .env или переменных окружения.

Авторизация: Проверяет валидность токена HF_TOKEN для работы с закрытыми репозиториями датасетов.

Проверка локальной копии: Проверяет наличие файла по указанному целевому пути. Если файл уже скачан, повторная загрузка пропускается.

Загрузка датасета: Запрашивает указанный WAV-файл из Hugging Face Dataset Hub (repo_type="dataset") и сохраняет его с сохранением структуры директорий.

Что создаётся в результате работы:
В директории {DATASET_DIR} (по умолчанию /content/F5-TTS/dataset) создаётся поддиректория и файл:

{WAV_FILENAME} — аудиофайл референсного голоса (например, wavs/000015.wav).

Источники данных:
Конфигурационный файл .env или переменные окружения.

Удалённый датасет на платформе Hugging Face Hub (repo_type="dataset").

Требования для запуска:
Установленные библиотеки Python: huggingface_hub, python-dotenv.

Переменные в .env:

Фрагмент кода
- HF_TOKEN=hf_xxx


Запуск:
Bash
```python download_dataset.py```
